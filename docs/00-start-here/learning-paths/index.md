# Learning paths

Learning paths are ordered routes through the library. Each has a goal, a sequence of topics and a milestone project that proves you have got there.

| Path | Level | Topics | Description |
| --- | --- | --- | --- |
| [Networking from zero](./networking-from-zero.md) | Beginner | 38 | From 'what is a packet?' to building, securing and troubleshooting a small enterprise network. Covers the CCNA, JNCIA and Network+ level. |
| [Enterprise networking professional](./enterprise-professional.md) | Intermediate | 27 | Advanced routing, campus and WAN design, virtualisation, security and assurance. Covers the CCNP Enterprise, JNCIS/JNCIP-ENT, HCIP-Datacom and Arista ACE L3–L4 level. |
| [Service provider networking](./service-provider.md) | Advanced | 21 | IS-IS, BGP at scale, MPLS, L3VPN, EVPN, Segment Routing, SRv6 and transport. Covers the CCNP/CCIE Service Provider, JNCIP/JNCIE-SP and Nokia SRC level. |
| [5G end to end](./5g-end-to-end.md) | Intermediate | 17 | From radio fundamentals to the 5G Core, Open RAN, slicing and 6G — the whole mobile system. |
| [Cloud native and data center networking](./cloud-native-networking.md) | Intermediate | 16 | Leaf-spine fabrics, EVPN-VXLAN, AI networking, data plane acceleration, Kubernetes, service mesh and public cloud. |
| [Network automation](./network-automation.md) | Intermediate | 12 | From Python scripts to model-driven, tested, pipeline-driven network changes — and AI-assisted operations. |

Paths overlap on purpose. If you have already covered a topic, tick it off and move on.
