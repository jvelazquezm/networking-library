# Learning paths

Learning paths are ordered routes through the library. Each one has a goal, a sequence of topics and a final milestone project that proves you have got there.

| Path | Level | Description |
| --- | --- | --- |
| [Networking from zero](./networking-from-zero.md) | Beginner | From 'what is a packet?' to building and troubleshooting a small routed network. Roughly CCNA level. |
| [5G end to end](./5g-end-to-end.md) | Intermediate | From radio fundamentals to the 5G Core, Open RAN and slicing — the whole mobile system. |
| [Cloud native networking](./cloud-native-networking.md) | Intermediate | Data center fabrics, overlays, Kubernetes networking, eBPF and service meshes. |
| [Network automation](./network-automation.md) | Intermediate | From Python scripts to model-driven, tested, CI/CD-driven network changes. |

Paths overlap on purpose — for example, Kubernetes networking appears in both *5G end to end* and *Cloud native networking*. If you have already covered a topic, tick it off and move on.

Want to propose a new path? See the [contribution guide](../contributing.md).
