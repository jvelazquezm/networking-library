# Enterprise networking professional

**Level:** Intermediate · **Topics:** 27

Advanced routing, campus and WAN design, virtualisation, security and assurance. Covers the CCNP Enterprise, JNCIS/JNCIP-ENT, HCIP-Datacom and Arista ACE L3–L4 level.

## Goal

Design, operate and troubleshoot multi-site enterprise networks with advanced routing, overlays, security and automation.

## Steps

1. [MST and spanning tree protection](../../02-switching/mst-and-stp-protection.md) (Intermediate) — Scale and protect spanning tree.
2. [EIGRP](../../04-routing/eigrp.md) (Intermediate) — Learn EIGRP for Cisco-heavy networks.
3. [OSPF](../../04-routing/ospf.md) (Beginner) — Go deep on multi-area OSPF.
4. [BGP fundamentals](../../04-routing/bgp-fundamentals.md) (Intermediate) — Learn BGP properly.
5. [Redistribution, route filtering and route maps](../../04-routing/redistribution-and-filtering.md) (Intermediate) — Control routes between protocols.
6. [Policy-based routing](../../04-routing/policy-based-routing.md) (Intermediate) — Override the routing table when needed.
7. [VRF and VRF-Lite](../../04-routing/vrf.md) (Intermediate) — Segment with VRFs.
8. [Fast convergence and high availability: BFD, GR/NSR, LFA and TI-LFA](../../04-routing/fast-convergence.md) (Advanced) — Converge in milliseconds.
9. [IP multicast: IGMP, PIM, SSM, MSDP and BIER](../../04-routing/multicast.md) (Intermediate) — Deliver one-to-many traffic.
10. [GRE tunnels](../../06-wan-and-vpn/gre.md) (Intermediate) — Build tunnels.
11. [IPsec and IKEv2](../../06-wan-and-vpn/ipsec.md) (Intermediate) — Encrypt them.
12. [DMVPN and NHRP](../../06-wan-and-vpn/dmvpn.md) (Advanced) — Scale site-to-site VPNs.
13. [SD-WAN](../../06-wan-and-vpn/sd-wan.md) (Intermediate) — Learn SD-WAN.
14. [LISP](../../06-wan-and-vpn/lisp.md) (Advanced) — Learn LISP.
15. [VXLAN, Geneve and EVPN](../../09-data-center-and-cloud/vxlan-evpn.md) (Intermediate) — Learn overlays.
16. [Campus fabrics: SD-Access, LISP and VXLAN](../../09-data-center-and-cloud/campus-fabrics.md) (Intermediate) — Build a campus fabric.
17. [Device hardening, AAA and CoPP](../../11-security/device-hardening-and-aaa.md) (Beginner) — Harden devices with AAA and CoPP.
18. [IPv6 first-hop security and uRPF](../../11-security/ipv6-security.md) (Intermediate) — Secure IPv6 access.
19. [802.1X and network access control](../../11-security/nac-and-8021x.md) (Intermediate) — Control network access.
20. [Firewalls, NGFW, IDS/IPS and proxies](../../11-security/firewalls-and-ips.md) (Intermediate) — Design zones and firewalls.
21. [Monitoring: SNMP, syslog, NetFlow, IPFIX and sFlow](../../12-operations/monitoring.md) (Beginner) — Monitor with SNMP, syslog and flows.
22. [Active monitoring: IP SLA, TWAMP and STAMP](../../12-operations/active-monitoring.md) (Intermediate) — Measure paths actively.
23. [Packet capture and port mirroring](../../12-operations/packet-capture.md) (Intermediate) — Capture packets anywhere.
24. [Python for network engineers](../../13-automation/python-for-networks.md) (Intermediate) — Script your work.
25. [YANG, NETCONF and RESTCONF](../../13-automation/yang-netconf-restconf.md) (Intermediate) — Use model-driven APIs.
26. [On-box automation: EEM and on-device Python](../../13-automation/on-box-automation.md) (Intermediate) — Automate on the device.
27. [Network design and high availability](../../12-operations/network-design.md) (Intermediate) — Design for availability.

## Milestone project

Build a dual-hub DMVPN or SD-WAN with BGP to two ISPs, a VXLAN/EVPN campus core, 802.1X access and automated backups with Python.
