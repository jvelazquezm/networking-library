# 5G end to end

**Level:** Intermediate · **Topics:** 17

From radio fundamentals to the 5G Core, Open RAN, slicing and 6G — the whole mobile system.

## Goal

Understand the full 5G System — radio, RAN, transport and core — and run an open-source 5G network in a lab.

## Steps

1. [Cellular fundamentals](../../08-mobile-networks/cellular-fundamentals.md) (Beginner) — Learn the radio ideas every generation shares.
2. [4G LTE and the EPC](../../08-mobile-networks/lte-and-epc.md) (Intermediate) — Understand 4G, which 5G evolved from.
3. [5G System architecture](../../08-mobile-networks/5g-system.md) (Intermediate) — Get the end-to-end picture.
4. [5G NR and NG-RAN](../../08-mobile-networks/5g-nr-and-ng-ran.md) (Advanced) — Go deep on NR and the gNB.
5. [SCTP and MPTCP](../../10-transport-and-applications/sctp-and-mptcp.md) (Advanced) — Learn the transports used in signalling.
6. [Metro, backhaul and fronthaul](../../07-service-provider/metro-backhaul-fronthaul.md) (Intermediate) — Understand how cell sites are connected.
7. [Timing and synchronization for transport networks](../../07-service-provider/timing-and-synchronization.md) (Advanced) — Learn why timing matters.
8. [Kubernetes networking](../../09-data-center-and-cloud/kubernetes-networking.md) (Intermediate) — Learn the platform the core runs on.
9. [Data plane acceleration: DPDK, SR-IOV, DPUs, eBPF/XDP and P4](../../09-data-center-and-cloud/data-plane-acceleration.md) (Advanced) — See how UPFs go fast.
10. [5G Core: SBA, PFCP, GTP-U and NGAP](../../08-mobile-networks/5g-core.md) (Advanced) — Go deep on the 5G Core.
11. [Voice: IMS, VoLTE and VoNR](../../08-mobile-networks/ims-and-voice.md) (Advanced) — Learn how voice works.
12. [Open RAN](../../08-mobile-networks/open-ran.md) (Advanced) — Understand Open RAN and the RIC.
13. [Network slicing](../../08-mobile-networks/network-slicing.md) (Advanced) — Learn slicing end to end.
14. [Private 5G and edge computing (MEC)](../../08-mobile-networks/private-5g-and-mec.md) (Intermediate) — Deploy 5G for enterprises.
15. [5G security](../../11-security/5g-security.md) (Advanced) — Understand 5G security.
16. [Non-terrestrial networks (NTN)](../../08-mobile-networks/non-terrestrial-networks.md) (Advanced) — Add satellites.
17. [6G](../../08-mobile-networks/6g.md) (Advanced) — Look ahead to 6G.

## Milestone project

Run Open5GS on Kubernetes with a simulated gNB and UEs, set up two slices and capture the full registration and session flow.
