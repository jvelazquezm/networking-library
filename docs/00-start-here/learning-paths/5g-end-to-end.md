# 5G end to end

**Level:** Intermediate · **Topics:** 12

## Goal

Understand the full 5G System — radio, RAN, transport and core — and be able to run an open source 5G network in a lab.

## Steps

1. [Cellular fundamentals](../../06-mobile-networks/cellular-fundamentals.md) (Beginner) — Learn the radio ideas every generation shares.
2. [4G LTE and the EPC](../../06-mobile-networks/lte-and-epc.md) (Intermediate) — Understand 4G, which 5G evolved from and still interworks with.
3. [5G System architecture](../../06-mobile-networks/5g-system-architecture.md) (Intermediate) — Get the end-to-end picture of the 5G System.
4. [5G NR and NG-RAN](../../06-mobile-networks/5g-ran.md) (Advanced) — Go deep on NR and the gNB.
5. [Metro, Carrier Ethernet and mobile backhaul](../../05-carrier-networks/metro-and-backhaul.md) (Intermediate) — Understand how cell sites are connected.
6. [Timing and synchronization](../../05-carrier-networks/timing-and-synchronization.md) (Advanced) — Learn why timing matters so much for radio.
7. [Kubernetes networking](../../07-data-center-and-cloud/kubernetes-networking.md) (Intermediate) — Learn the platform the 5G Core runs on.
8. [5G Core (5GC)](../../06-mobile-networks/5g-core.md) (Advanced) — Go deep on the service-based core.
9. [Open RAN](../../06-mobile-networks/open-ran.md) (Advanced) — Understand open, disaggregated RAN and the RIC.
10. [Network slicing](../../06-mobile-networks/network-slicing.md) (Advanced) — Learn how one network serves many use cases.
11. [5G security](../../09-security/5g-security.md) (Advanced) — Understand the 5G security architecture.
12. [6G](../../06-mobile-networks/6g.md) (Advanced) — Look ahead to 6G.

## Milestone project

Run Open5GS with a simulated gNB and UE, set up two slices and capture the full registration and session flow.

:::tip How to work through a path
Read the overview and key concepts of each topic, do its hands-on lab, and only move on when you can explain every key concept without notes.
:::
