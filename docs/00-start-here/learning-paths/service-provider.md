# Service provider networking

**Level:** Advanced · **Topics:** 21

IS-IS, BGP at scale, MPLS, L3VPN, EVPN, Segment Routing, SRv6 and transport. Covers the CCNP/CCIE Service Provider, JNCIP/JNCIE-SP and Nokia SRC level.

## Goal

Design and operate an operator backbone with modern Segment Routing and EVPN services.

## Steps

1. [Service provider architecture, peering and IXPs](../../07-service-provider/sp-architecture.md) (Intermediate) — Understand how operators are organised.
2. [IS-IS](../../04-routing/is-is.md) (Intermediate) — Learn the operator IGP.
3. [Advanced BGP](../../04-routing/bgp-advanced.md) (Advanced) — Run BGP at scale.
4. [Fast convergence and high availability: BFD, GR/NSR, LFA and TI-LFA](../../04-routing/fast-convergence.md) (Advanced) — Protect traffic with fast reroute.
5. [MPLS and LDP](../../07-service-provider/mpls.md) (Intermediate) — Learn label switching.
6. [MPLS L3VPN, 6PE and 6VPE](../../07-service-provider/mpls-l3vpn.md) (Intermediate) — Deliver L3VPN services.
7. [L2VPN: pseudowires and VPLS](../../07-service-provider/l2vpn.md) (Advanced) — Deliver L2VPN services.
8. [EVPN](../../07-service-provider/evpn.md) (Advanced) — Move to EVPN.
9. [Traffic engineering: RSVP-TE](../../07-service-provider/traffic-engineering.md) (Advanced) — Engineer traffic the classic way.
10. [Segment Routing: SR-MPLS](../../07-service-provider/segment-routing.md) (Advanced) — Adopt Segment Routing.
11. [SRv6 and uSID](../../07-service-provider/srv6.md) (Advanced) — Go native IPv6 with SRv6.
12. [SDN for the WAN: PCE, PCEP and BGP-LS](../../07-service-provider/pce-and-bgp-ls.md) (Advanced) — Centralise path computation.
13. [IP multicast: IGMP, PIM, SSM, MSDP and BIER](../../04-routing/multicast.md) (Intermediate) — Deliver multicast services.
14. [Quality of Service (QoS)](../../05-ip-services/qos.md) (Beginner) — Apply QoS in the core.
15. [Broadband access: PON, DOCSIS, BNG, PPPoE and IPoE](../../07-service-provider/broadband-access.md) (Intermediate) — Understand subscriber access.
16. [Metro, backhaul and fronthaul](../../07-service-provider/metro-backhaul-fronthaul.md) (Intermediate) — Transport mobile traffic.
17. [Timing and synchronization for transport networks](../../07-service-provider/timing-and-synchronization.md) (Advanced) — Distribute time.
18. [Optical transport: DWDM and OTN](../../07-service-provider/optical-transport.md) (Advanced) — Understand the optical layer.
19. [Routing security: RPKI, ASPA and BGPsec](../../11-security/routing-security.md) (Intermediate) — Secure the routing system.
20. [DDoS and BGP Flowspec](../../11-security/ddos.md) (Intermediate) — Defend against DDoS.
21. [Model-driven telemetry and operations: gNMI, gNOI and gRPC](../../13-automation/model-driven-telemetry.md) (Intermediate) — Observe the network with telemetry.

## Milestone project

Build an IS-IS/SR-MPLS (or SRv6) core with TI-LFA, route reflectors, L3VPN and EVPN services, RPKI validation and gNMI telemetry.

:::tip How to work through a path
Read the overview and key concepts of each topic, do its hands-on lab, and move on only when you can explain every key concept without notes.
:::
