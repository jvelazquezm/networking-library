# Networking from zero

**Level:** Beginner · **Topics:** 15

## Goal

Understand how data moves across a network and be able to build, secure and troubleshoot a small routed network.

## Steps

1. [Network models: OSI and TCP/IP](../../01-fundamentals/network-models.md) (Beginner) — Learn the layered model you will use for everything else.
2. [Physical layer and media](../../01-fundamentals/physical-layer.md) (Beginner) — Understand media and the physical limits of links.
3. [IPv4 addressing and subnetting](../../01-fundamentals/ipv4-addressing.md) (Beginner) — Master addressing and subnetting — practise until it is automatic.
4. [ARP and ICMP](../../01-fundamentals/arp-and-icmp.md) (Beginner) — See how the first hop really works.
5. [Ethernet and switching](../../02-lan-and-switching/ethernet.md) (Beginner) — Learn how switches forward frames.
6. [VLANs and trunking](../../02-lan-and-switching/vlans.md) (Beginner) — Segment the LAN.
7. [Spanning tree and loop prevention](../../02-lan-and-switching/spanning-tree.md) (Intermediate) — Keep Layer 2 loop-free.
8. [Routing fundamentals](../../03-routing/routing-fundamentals.md) (Beginner) — Move packets between networks.
9. [OSPF](../../03-routing/ospf.md) (Intermediate) — Run your first dynamic routing protocol.
10. [NAT and DHCP](../../01-fundamentals/nat-and-dhcp.md) (Beginner) — Connect the network to the Internet.
11. [IPv6](../../01-fundamentals/ipv6.md) (Beginner) — Add IPv6.
12. [TCP and congestion control](../../04-transport-and-applications/tcp.md) (Intermediate) — Understand transport and why the network feels slow.
13. [DNS](../../04-transport-and-applications/dns.md) (Beginner) — Learn how names become addresses.
14. [Security fundamentals for networks](../../09-security/security-fundamentals.md) (Beginner) — Learn the security basics.
15. [Troubleshooting methodology](../../10-operations/troubleshooting.md) (Beginner) — Put it all together by fixing broken networks.

## Milestone project

Build a two-site network with VLANs, OSPF, NAT and DHCP in a virtual lab, then document and troubleshoot it.

:::tip How to work through a path
Read the overview and key concepts of each topic, do its hands-on lab, and only move on when you can explain every key concept without notes.
:::
