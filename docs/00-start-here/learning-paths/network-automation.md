# Network automation

**Level:** Intermediate · **Topics:** 7

## Goal

Manage a network as code: model-driven interfaces, automation frameworks, testing and pipelines.

## Steps

1. [Automation tools: Python, Ansible and friends](../../08-automation/automation-tools.md) (Intermediate) — Start with Python, Netmiko and Ansible.
2. [YANG data models](../../08-automation/yang-data-models.md) (Intermediate) — Learn how configuration is modelled.
3. [NETCONF and RESTCONF](../../08-automation/netconf-restconf.md) (Intermediate) — Configure devices through APIs.
4. [Streaming telemetry and gNMI](../../08-automation/streaming-telemetry.md) (Advanced) — Collect state with streaming telemetry.
5. [Monitoring and observability](../../10-operations/monitoring-and-observability.md) (Intermediate) — Turn data into observability.
6. [NetDevOps: testing and CI/CD](../../08-automation/netdevops.md) (Advanced) — Test and deploy changes with CI/CD.
7. [Intent-based networking and AI for networks](../../08-automation/intent-and-ai.md) (Advanced) — Move towards intent and closed loops.

## Milestone project

Store your lab's intent in NetBox, generate configs, validate them with Batfish in CI and deploy automatically on merge.

:::tip How to work through a path
Read the overview and key concepts of each topic, do its hands-on lab, and only move on when you can explain every key concept without notes.
:::
