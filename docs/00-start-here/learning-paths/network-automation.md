# Network automation

**Level:** Intermediate · **Topics:** 12

From Python scripts to model-driven, tested, pipeline-driven network changes — and AI-assisted operations.

## Goal

Manage a network as code with model-driven interfaces, a source of truth, testing and pipelines.

## Steps

1. [Network management approaches](../../13-automation/management-approaches.md) (Beginner) — Understand the options.
2. [Data formats: JSON, XML and YAML](../../13-automation/data-formats.md) (Beginner) — Learn the data formats.
3. [REST APIs](../../13-automation/rest-apis.md) (Beginner) — Call APIs.
4. [Configuration management: Ansible, Terraform, Puppet and Chef](../../13-automation/configuration-management.md) (Beginner) — Start with Ansible.
5. [Python for network engineers](../../13-automation/python-for-networks.md) (Intermediate) — Learn Python for networks.
6. [Templating and source of truth: Jinja2 and NetBox](../../13-automation/templating-and-source-of-truth.md) (Intermediate) — Separate data from configuration.
7. [YANG, NETCONF and RESTCONF](../../13-automation/yang-netconf-restconf.md) (Intermediate) — Use model-driven interfaces.
8. [Model-driven telemetry and operations: gNMI, gNOI and gRPC](../../13-automation/model-driven-telemetry.md) (Intermediate) — Stream telemetry.
9. [Observability stack: Prometheus and Grafana](../../12-operations/observability-stack.md) (Intermediate) — Build an observability stack.
10. [On-box automation: EEM and on-device Python](../../13-automation/on-box-automation.md) (Intermediate) — Automate on the device.
11. [NetDevOps, CI/CD and digital twins](../../13-automation/netdevops.md) (Advanced) — Test and deploy with CI/CD.
12. [AI in network operations](../../13-automation/ai-for-networks.md) (Beginner) — Add AI with guardrails.

## Milestone project

Store your lab's intent in NetBox, generate configs, validate them in CI with Containerlab and Batfish, deploy on merge and stream telemetry to Grafana.
