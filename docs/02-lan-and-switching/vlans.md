# VLANs and trunking

**Level:** Beginner · **Section:** [LAN and Switching](./index.md)

## Overview

Segmenting one physical network into many logical ones, tagging frames and routing between VLANs.

## Key concepts

- 802.1Q tags
- Access vs trunk ports
- Native VLAN
- Inter-VLAN routing (router-on-a-stick, SVIs)
- Private VLANs
