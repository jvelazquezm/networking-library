# Port security and network access control

**Level:** Intermediate · **Section:** [LAN and Switching](./index.md)

## Overview

Controlling who can plug into the network: 802.1X, MAC authentication and common Layer 2 attacks and defences.

## Key concepts

- 802.1X roles (supplicant, authenticator, server)
- RADIUS
- MAC Authentication Bypass
- DHCP snooping, dynamic ARP inspection
- MAC flooding and VLAN hopping
