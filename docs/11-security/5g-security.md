# 5G security

**Level:** Advanced · **Section:** [Security](./index.md)

## Overview

5G fixed several weaknesses of earlier generations: the permanent identifier is concealed (SUCI), authentication is unified (5G-AKA, EAP-AKA'), the home network confirms authentication and the service-based core uses TLS and OAuth 2.0 between functions. Roaming signalling passes through security edge protection proxies. Open RAN and cloud-native deployments add new attack surface to manage.

## Key concepts

- 5G-AKA and EAP-AKA'
- SUPI concealment (SUCI)
- Key hierarchy
- SBA security: TLS and OAuth 2.0
- SEPP and roaming security
- Network slicing security
- Open RAN and cloud-native threats
