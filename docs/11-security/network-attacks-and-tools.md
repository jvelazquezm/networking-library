# Network attacks and assessment tools

**Level:** Intermediate · **Section:** [Security](./index.md)

## Overview

Understanding attacks makes you a better defender. Reconnaissance with scanners, spoofing and man-in-the-middle at Layer 2 and 3, protocol abuse and misconfiguration are the usual entry points. The same tools — nmap, Wireshark, Scapy, Responder-style tools — let you audit your own networks. Always test only networks you are authorised to test.

## Key concepts

- Reconnaissance and scanning
- Spoofing and man-in-the-middle
- Protocol and routing attacks
- Wireless attacks
- Vulnerability scanning
- Legal and ethical boundaries
