# Security concepts and programs

**Level:** Beginner · **Section:** [Security](./index.md)

## Overview

Security starts with vocabulary and mindset: what you are protecting (confidentiality, integrity, availability), from whom, and how. Threats exploit vulnerabilities; controls reduce risk; layers of defence make single failures survivable. Technical controls only work inside a programme that includes user awareness, physical security and incident response.

## Key concepts

- Threats, vulnerabilities, exploits and mitigation
- Confidentiality, integrity, availability
- Defence in depth
- Common attack types
- User awareness, training and physical access control
- Frameworks: NIST CSF, CIS Controls
