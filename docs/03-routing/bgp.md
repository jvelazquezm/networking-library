# BGP

**Level:** Intermediate · **Section:** [Routing and Internet Architecture](./index.md)

## Overview

The protocol that holds the Internet together: path attributes, policy, iBGP vs eBGP and the best-path algorithm.

## Key concepts

- Sessions and states
- Path attributes (AS_PATH, LOCAL_PREF, MED, communities)
- Best-path selection
- iBGP, route reflectors and confederations
- Multiprotocol BGP
- Peering and transit
