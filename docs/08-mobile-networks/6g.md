# 6G

**Level:** Advanced · **Section:** [Mobile Networks](./index.md)

## Overview

ITU-R's IMT-2030 framework defines the goals for 6G, and 3GPP began 6G study work in Release 20, with specifications expected towards the end of the decade. Key themes include an AI-native air interface, integrated sensing and communication, new spectrum in the upper mid-band and sub-THz, native NTN integration and sustainability.

## Key concepts

- IMT-2030 usage scenarios
- AI-native air interface
- Integrated sensing and communication
- Upper mid-band and sub-THz spectrum
- Native NTN integration
- 3GPP 6G timeline (Release 20 onwards)
