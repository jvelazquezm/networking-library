# Private 5G and edge computing (MEC)

**Level:** Intermediate · **Section:** [Mobile Networks](./index.md)

## Overview

Private 5G networks give factories, ports and campuses dedicated mobile coverage with predictable performance, often on locally licensed spectrum. Edge computing places applications close to the radio to cut latency, with the UPF breaking out traffic locally. Cloud providers and open-source projects have made small private networks far easier to deploy.

## Key concepts

- Private, hybrid and neutral-host models
- Local and shared spectrum
- Local breakout and UPF at the edge
- ETSI MEC framework
- Private 5G vs Wi-Fi
- Industrial use cases
