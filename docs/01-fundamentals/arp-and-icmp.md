# ARP and ICMP

**Level:** Beginner · **Section:** [Fundamentals](./index.md)

## Overview

How IP addresses are resolved to MAC addresses on a link, and how ICMP reports errors and powers tools like ping and traceroute.

## Key concepts

- ARP request/reply and caches
- Gratuitous ARP
- ICMP message types
- How traceroute works
- Path MTU discovery

- None beyond the earlier topics in this section.
