# 01 · Fundamentals

The concepts everything else builds on: how communication is layered, how hosts are addressed and how packets find their first hop. If you are new to networking, start here and do not skip subnetting.

## Topics in this section

| Topic | Level | What you will learn |
| --- | --- | --- |
| [Network models: OSI and TCP/IP](./network-models.md) | Beginner | Why networks are built in layers, how the seven-layer OSI model compares with the four-layer TCP/IP model, and how encapsulation works in practice. |
| [Physical layer and media](./physical-layer.md) | Beginner | Copper, fibre and radio as transmission media: signalling, bandwidth, attenuation and the cabling standards used in practice. |
| [IPv4 addressing and subnetting](./ipv4-addressing.md) | Beginner | The IPv4 header, address classes and why CIDR replaced them, private address space and how to subnet confidently. |
| [IPv6](./ipv6.md) | Beginner | The IPv6 header and address architecture, neighbour discovery, autoconfiguration and how IPv6 coexists with IPv4. |
| [ARP and ICMP](./arp-and-icmp.md) | Beginner | How IP addresses are resolved to MAC addresses on a link, and how ICMP reports errors and powers tools like ping and traceroute. |
| [NAT and DHCP](./nat-and-dhcp.md) | Beginner | How hosts get their configuration automatically and how address translation lets private networks reach the Internet. |

[Network models: OSI and TCP/IP](./network-models.md) → [Physical layer and media](./physical-layer.md) → [IPv4 addressing and subnetting](./ipv4-addressing.md) → [IPv6](./ipv6.md) → [ARP and ICMP](./arp-and-icmp.md) → [NAT and DHCP](./nat-and-dhcp.md)
