# Networking devices and their roles

**Level:** Beginner · **Section:** [Network Fundamentals](./index.md)

## Overview

Each device type exists to solve a specific problem: switches forward frames inside a LAN, routers move packets between networks, firewalls enforce security policy, access points bridge wireless clients onto the wired network and controllers manage fleets of devices centrally. Many modern boxes combine roles (Layer 3 switches, next-generation firewalls), so it is worth understanding the function rather than the product label.

## Key concepts

- Hubs (historical), switches and Layer 3 switches
- Routers
- Firewalls and next-generation firewalls
- Wireless access points and controllers
- Endpoints and servers
- Appliances vs virtual network functions
