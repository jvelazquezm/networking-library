# 05 · IP Services

The services that make an IP network usable and manageable: automatic addressing, naming, address translation, accurate time, traffic prioritisation, secure management access and real-time voice and video.

## Topics in this section

| Topic | Level | What you will learn |
| --- | --- | --- |
| [DHCP and DHCPv6](./dhcp.md) | Beginner | Automatic host configuration: the DHCP exchange, options, relays, DHCPv6 and how to troubleshoot it. |
| [DNS, DNSSEC, DoT and DoH](./dns.md) | Beginner | The Internet's naming system: hierarchy, resolution, record types, caching, DNSSEC and encrypted DNS. |
| [NAT and PAT](./nat.md) | Beginner | Network address translation: static NAT, dynamic NAT, PAT/overload, port forwarding and carrier-grade NAT. |
| [Time: NTP, NTS and PTP](./time-synchronization.md) | Beginner | Why accurate time matters and how NTP, Network Time Security and the Precision Time Protocol deliver it. |
| [Quality of Service (QoS)](./qos.md) | Beginner | Classification, marking, queuing, policing, shaping and congestion avoidance — and how to design an end-to-end policy. |
| [Device management: SSH, SNMP, syslog, TFTP, FTP and SFTP](./device-management.md) | Beginner | Secure remote access, basic monitoring and moving files to and from network devices. |
| [Voice and video over IP: SIP and RTP](./voice-and-video.md) | Intermediate | How real-time communications work on IP networks: signalling with SIP, media with RTP, codecs and network requirements. |
