# 08 · Automation and Programmability

Managing networks as code: data models and programmatic interfaces, automation frameworks, testing and CI/CD, and the move towards intent-based and AI-driven operations.

## Topics in this section

| Topic | Level | What you will learn |
| --- | --- | --- |
| [YANG data models](./yang-data-models.md) | Intermediate | The language used to model network configuration and state, and the OpenConfig and IETF model families. |
| [NETCONF and RESTCONF](./netconf-restconf.md) | Intermediate | Transactional, model-driven configuration of network devices over SSH (NETCONF) or HTTP (RESTCONF). |
| [Streaming telemetry and gNMI](./streaming-telemetry.md) | Advanced | Replacing polling with push: model-driven telemetry over gNMI and how to build a modern collection pipeline. |
| [Automation tools: Python, Ansible and friends](./automation-tools.md) | Intermediate | The practical toolbox of network automation: Python libraries, Ansible, sources of truth and templating. |
| [NetDevOps: testing and CI/CD](./netdevops.md) | Advanced | Applying software engineering practice to networks: version control, pre-change validation, digital twins and pipelines. |
| [Intent-based networking and AI for networks](./intent-and-ai.md) | Advanced | Declaring what the network should do instead of how, and where machine learning and AI agents fit into network operations. |

[YANG data models](./yang-data-models.md) → [NETCONF and RESTCONF](./netconf-restconf.md) → [Automation tools: Python, Ansible and friends](./automation-tools.md) → [Streaming telemetry and gNMI](./streaming-telemetry.md) → [NetDevOps: testing and CI/CD](./netdevops.md) → [Intent-based networking and AI for networks](./intent-and-ai.md)
