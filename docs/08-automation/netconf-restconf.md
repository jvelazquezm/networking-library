# NETCONF and RESTCONF

**Level:** Intermediate · **Section:** [Automation and Programmability](./index.md)

## Overview

## Key concepts

- Datastores (running, candidate, startup)
- Operations and transactions
- RESTCONF over HTTP
- Python ncclient
