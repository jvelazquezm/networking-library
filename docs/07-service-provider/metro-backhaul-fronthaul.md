# Metro, backhaul and fronthaul

**Level:** Intermediate · **Section:** [Service Provider and Transport Networks](./index.md)

## Overview

Mobile base stations need transport with strict capacity, latency and timing requirements. Backhaul connects the base station to the core, midhaul connects split RAN units, and fronthaul carries radio samples between radio and baseband units with microsecond budgets. Metro networks built on Carrier Ethernet, MPLS or SR deliver these alongside enterprise services.

## Key concepts

- Carrier Ethernet services (E-Line, E-LAN, E-Tree)
- Backhaul, midhaul and fronthaul
- CPRI and eCPRI
- O-RAN 7.2x fronthaul
- Latency and capacity budgets
- Packet-based vs optical fronthaul
