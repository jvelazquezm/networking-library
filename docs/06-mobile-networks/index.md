# 06 · Mobile Networks

Everything about cellular networks, from radio fundamentals to the 5G System, open and disaggregated RAN, slicing and the road to 6G. 3GPP specifications are the source of truth here, and the release matters: always note which release a resource refers to.

## Topics in this section

| Topic | Level | What you will learn |
| --- | --- | --- |
| [Cellular fundamentals](./cellular-fundamentals.md) | Beginner | The ideas behind every mobile generation: cells and reuse, spectrum, OFDM, MIMO and mobility. |
| [4G LTE and the EPC](./lte-and-epc.md) | Intermediate | The architecture of 4G: E-UTRAN, eNodeB, the Evolved Packet Core and the bearer model that 5G evolved from. |
| [5G System architecture](./5g-system-architecture.md) | Intermediate | The end-to-end 5G System: NG-RAN, the service-based core, standalone vs non-standalone and the key procedures. |
| [5G NR and NG-RAN](./5g-ran.md) | Advanced | The 5G radio: numerologies, the NR protocol stack and the CU/DU split of the gNB. |
| [5G Core (5GC)](./5g-core.md) | Advanced | The cloud native core network: AMF, SMF, UPF and friends, the service-based interfaces and how it runs on Kubernetes. |
| [Open RAN](./open-ran.md) | Advanced | Disaggregating the radio access network: the O-RAN architecture, open fronthaul, the RIC and xApps/rApps. |
| [Network slicing](./network-slicing.md) | Advanced | Running multiple logical networks with different guarantees on shared infrastructure, end to end across RAN, transport and core. |
| [Non-terrestrial networks (NTN)](./non-terrestrial-networks.md) | Advanced | Satellites and high-altitude platforms as part of the mobile network, as standardised from 3GPP Release 17 onwards. |
| [6G](./6g.md) | Advanced | What comes after 5G: the IMT-2030 vision, research directions and the 3GPP timeline. |
