# Open RAN

**Level:** Advanced · **Section:** [Mobile Networks](./index.md)

## Overview

Disaggregating the radio access network: the O-RAN architecture, open fronthaul, the RIC and xApps/rApps.

## Key concepts

- O-RAN architecture (O-RU, O-DU, O-CU)
- Open fronthaul (7.2x)
- Near-RT RIC and xApps
- Non-RT RIC, SMO and rApps
- E2, A1 and O1 interfaces
- Interoperability and testing
