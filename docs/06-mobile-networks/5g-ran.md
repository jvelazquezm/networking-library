# 5G NR and NG-RAN

**Level:** Advanced · **Section:** [Mobile Networks](./index.md)

## Overview

The 5G radio: numerologies, the NR protocol stack and the CU/DU split of the gNB.

## Key concepts

- Numerologies and frame structure
- NR protocol stack (SDAP, PDCP, RLC, MAC, PHY)
- gNB-CU / gNB-DU split
- Massive MIMO
- Functional splits (7.2x)
