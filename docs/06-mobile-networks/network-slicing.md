# Network slicing

**Level:** Advanced · **Section:** [Mobile Networks](./index.md)

## Overview

Running multiple logical networks with different guarantees on shared infrastructure, end to end across RAN, transport and core.

## Key concepts

- S-NSSAI and slice selection
- Slice types (eMBB, URLLC, mMTC)
- Slice management and orchestration
- Transport slicing
- Slice SLAs
