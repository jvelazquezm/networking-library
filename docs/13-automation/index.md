# 13 · Automation, Programmability and AI

Managing networks as code: the data formats and APIs devices expose, the tools that push configuration and collect state, the model-driven interfaces of modern platforms, the engineering practices that make change safe, and the growing role of AI in network operations.

## Topics in this section

| Topic | Level | What you will learn |
| --- | --- | --- |
| [Network management approaches](./management-approaches.md) | Beginner | From box-by-box CLI to automation, infrastructure as code, controller-based and cloud-managed networks. |
| [Data formats: JSON, XML and YAML](./data-formats.md) | Beginner | The structured data formats used by APIs and automation tools, and how to read and write them. |
| [REST APIs](./rest-apis.md) | Beginner | How REST APIs work: resources, HTTP methods and CRUD, status codes, authentication and tools like curl and Postman. |
| [Configuration management: Ansible, Terraform, Puppet and Chef](./configuration-management.md) | Beginner | Tools that apply configuration at scale: agentless vs agent-based, push vs pull, declarative vs procedural. |
| [Python for network engineers](./python-for-networks.md) | Intermediate | Python fundamentals applied to networks: connecting to devices, parsing output, calling APIs and building small tools. |
| [Templating and source of truth: Jinja2 and NetBox](./templating-and-source-of-truth.md) | Intermediate | Generating configurations from data with Jinja2, and keeping intended state in a source of truth such as NetBox. |
| [YANG, NETCONF and RESTCONF](./yang-netconf-restconf.md) | Intermediate | Model-driven management: YANG data models (IETF, OpenConfig, native), NETCONF transactions and RESTCONF over HTTP. |
| [Model-driven telemetry and operations: gNMI, gNOI and gRPC](./model-driven-telemetry.md) | Intermediate | Streaming state from devices with gNMI subscriptions, operating them with gNOI, and building a telemetry pipeline. |
| [On-box automation: EEM and on-device Python](./on-box-automation.md) | Intermediate | Automation that runs on the device itself: event-driven scripts, Cisco EEM, Junos event and commit scripts, and on-box Python. |
| [NetDevOps, CI/CD and digital twins](./netdevops.md) | Advanced | Software engineering practices for networks: Git workflows, testing, virtual labs, pre-change validation and pipelines. |
| [AI in network operations](./ai-for-networks.md) | Beginner | Machine learning, generative AI and AI agents in networking: analytics, anomaly detection, prompting and agentic operations. |
