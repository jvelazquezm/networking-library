# Network management approaches

**Level:** Beginner · **Section:** [Automation, Programmability and AI](./index.md)

## Overview

Networks used to be managed one device at a time over the CLI. Today teams choose between, or combine, script-based automation, infrastructure as code with version control, controllers that own the configuration (campus fabrics, SD-WAN) and cloud dashboards. Each changes who holds the source of truth and how changes are made, tested and rolled back. This comparison is new in the CCNA v2.0 blueprint.

## Key concepts

- Device-by-device management
- Script- and tool-based automation
- Infrastructure as code
- Controller-based management
- Cloud-managed networks
- Source of truth and drift
- Benefits and risks of automation
