# AI in network operations

**Level:** Beginner · **Section:** [Automation, Programmability and AI](./index.md)

## Overview

AI is entering network operations at several levels: machine learning for anomaly detection and predictive analytics, AI assistants that explain configurations and logs, and agents that call APIs to gather telemetry, troubleshoot and propose changes. Using them well requires good prompts — clear instructions, data classification, output format and role — and guardrails so that nothing reaches production unchecked. The CCNA v2.0 blueprint now includes prompt construction and agentic AI.

## Key concepts

- Predictive analytics and anomaly detection
- Generative AI assistants for engineers
- Prompt construction: instructions, persona, output format, data classification
- AI agents calling APIs for telemetry and troubleshooting
- Guardrails, human approval and auditability
- Data privacy when using AI tools
- AI in the RAN (RIC apps)
