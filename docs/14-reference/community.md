# Community

Networking is a field where practitioners share generously. These are good places to keep learning after the fundamentals.

## Blogs and articles

| Source | Focus |
| --- | --- |
| [ipSpace.net blog](https://blog.ipspace.net/) | In-depth, vendor-neutral analysis of routing, data centre and automation |
| [APNIC Blog](https://blog.apnic.net/) | Internet operations, routing security, measurement |
| [RIPE Labs](https://labs.ripe.net/) | Research and operations from the RIPE community |
| [Cloudflare Blog](https://blog.cloudflare.com/) | Internet protocols, DDoS, post-quantum, performance |
| [Practical Networking](https://www.practicalnetworking.net/) | Clear explanations of CCNA-level topics |
| [segment-routing.net](https://www.segment-routing.net/) | Segment Routing |
| [srv6.md](https://srv6.md/) | SRv6 |
