# Huawei

Huawei's datacom track has three levels: HCIA-Datacom, HCIP-Datacom (a core exam plus specialisations) and HCIE-Datacom (written and lab exams).

| Level | Scope | Library topics |
| --- | --- | --- |
| HCIA-Datacom | Networking fundamentals, switching, routing, WLAN, security and automation basics | Sections [01](../../01-fundamentals/index.md), [02](../../02-switching/index.md), [03](../../03-wireless/index.md), [04](../../04-routing/index.md) and [05](../../05-ip-services/index.md); [Access control lists](../../11-security/acls.md), [Network management approaches](../../13-automation/management-approaches.md) |
| HCIP-Datacom | Core technology plus specialisations: advanced routing and switching, campus networks, WAN planning, SD-WAN and network automation | [OSPF](../../04-routing/ospf.md), [IS-IS](../../04-routing/is-is.md), [Advanced BGP](../../04-routing/bgp-advanced.md), [IP multicast: IGMP, PIM, SSM, MSDP and BIER](../../04-routing/multicast.md), [MPLS and LDP](../../07-service-provider/mpls.md), [MPLS L3VPN, 6PE and 6VPE](../../07-service-provider/mpls-l3vpn.md), [VXLAN, Geneve and EVPN](../../09-data-center-and-cloud/vxlan-evpn.md), [Campus fabrics: SD-Access, LISP and VXLAN](../../09-data-center-and-cloud/campus-fabrics.md), [SD-WAN](../../06-wan-and-vpn/sd-wan.md), [YANG, NETCONF and RESTCONF](../../13-automation/yang-netconf-restconf.md) |
| HCIE-Datacom | Advanced routing and switching, campus network planning and deployment, WAN interconnection (including SD-WAN), bearer WAN, network automation | [Advanced BGP](../../04-routing/bgp-advanced.md), [Segment Routing: SR-MPLS](../../07-service-provider/segment-routing.md), [SRv6 and uSID](../../07-service-provider/srv6.md), [EVPN](../../07-service-provider/evpn.md), [Campus fabrics: SD-Access, LISP and VXLAN](../../09-data-center-and-cloud/campus-fabrics.md), [SD-WAN](../../06-wan-and-vpn/sd-wan.md), [Python for network engineers](../../13-automation/python-for-networks.md), [NetDevOps, CI/CD and digital twins](../../13-automation/netdevops.md) |

Official information: [Huawei certification](https://e.huawei.com/en/talent/cert/).

:::note
Huawei names some technologies differently (for example "bearer WAN" for the operator-style SR/SRv6 backbone). Check the official exam outline for exact scope.
:::
