## Certifications

| Track | Vendor | Focus |
| --- | --- | --- |
| [Network+](https://www.comptia.org/) | CompTIA | Vendor-neutral fundamentals |
| [CCNA → CCNP → CCIE](https://www.cisco.com/) | Cisco | Enterprise and service provider networking |
| [JNCIA → JNCIP → JNCIE](https://www.juniper.net/) | Juniper Networks | Routing, switching and automation |
| [Nokia SRC](https://www.nokia.com/) | Nokia | Service provider routing |
| [CWNA and the CWNP track](https://www.cwnp.com/) | CWNP | Vendor-neutral Wi-Fi |
| [KCNA, CKA](https://www.cncf.io/) | CNCF / Linux Foundation | Kubernetes and cloud native |

:::tip Certifications vs learning
Certifications give structure and are valued by employers, but they lag behind the technology. Use them as a scaffold and complement them with the standards and labs in this library.
:::
