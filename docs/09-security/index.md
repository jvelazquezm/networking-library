# 09 · Network Security

Protecting networks and the traffic they carry: segmentation and filtering, encrypted tunnels, Zero Trust, securing the routing system itself and the security architecture of mobile networks.

## Topics in this section

| Topic | Level | What you will learn |
| --- | --- | --- |
| [Security fundamentals for networks](./security-fundamentals.md) | Beginner | The core ideas: the CIA triad, threat modelling, defence in depth and the most common network attacks. |
| [Firewalls and segmentation](./firewalls-and-segmentation.md) | Intermediate | Stateless and stateful filtering, next-generation firewalls and how to segment networks effectively. |
| [VPNs, IPsec and WireGuard](./vpn-and-ipsec.md) | Intermediate | Building encrypted tunnels: IPsec with IKEv2, WireGuard, and site-to-site vs remote-access designs. |
| [Zero Trust](./zero-trust.md) | Intermediate | Never trust, always verify: identity-centric access, policy engines and how Zero Trust changes network design. |
| [Routing security (RPKI)](./routing-security.md) | Advanced | Protecting the Internet's routing system from hijacks and leaks with RPKI, filtering and community best practice. |
| [DDoS attacks and mitigation](./ddos.md) | Intermediate | How volumetric, protocol and application-layer attacks work, and how operators and CDNs absorb them. |
| [5G security](./5g-security.md) | Advanced | The security architecture of the 5G System: authentication, subscriber privacy, SBA security and the attack surface of open, cloud native networks. |
