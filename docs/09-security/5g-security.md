# 5G security

**Level:** Advanced · **Section:** [Network Security](./index.md)

## Overview

The security architecture of the 5G System: authentication, subscriber privacy, SBA security and the attack surface of open, cloud native networks.

## Key concepts

- 5G-AKA and EAP-AKA'
- SUPI concealment (SUCI)
- SBA security and OAuth 2.0
- Security edge protection (SEPP)
- Open RAN and cloud native attack surface
