# Metro, backhaul y fronthaul

**Nivel:** Intermedio · **Sección:** [Redes de operador y transporte](./index.md)

## Visión general

Las estaciones base móviles necesitan un transporte con requisitos estrictos de capacidad, latencia y sincronización. El backhaul conecta la estación base con el núcleo, el midhaul conecta las unidades de una RAN dividida y el fronthaul transporta muestras de radio entre la unidad de radio y la de banda base con presupuestos de microsegundos. Las redes metro construidas con Carrier Ethernet, MPLS o SR entregan estos servicios junto a los empresariales.

## Conceptos clave

- Servicios Carrier Ethernet (E-Line, E-LAN, E-Tree)
- Backhaul, midhaul y fronthaul
- CPRI y eCPRI
- Fronthaul O-RAN 7.2x
- Presupuestos de latencia y capacidad
- Fronthaul por paquetes frente a óptico
