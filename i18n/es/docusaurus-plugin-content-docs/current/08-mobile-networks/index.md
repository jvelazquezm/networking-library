# 08 · Redes móviles

Todo sobre las redes celulares, desde los fundamentos de radio hasta el sistema 5G, la RAN abierta y desagregada, el network slicing, las redes privadas y el camino hacia el 6G. Las especificaciones del 3GPP son aquí la fuente de verdad y la release importa: anota siempre a qué release se refiere cada recurso.

## Temas de esta sección

| Tema | Nivel | Qué aprenderás |
| --- | --- | --- |
| [Fundamentos celulares](./cellular-fundamentals.md) | Principiante | Las ideas detrás de todas las generaciones móviles: celdas y reutilización, espectro, dúplex, OFDM, MIMO, movilidad. |
| [4G LTE y el EPC](./lte-and-epc.md) | Intermedio | La arquitectura 4G: E-UTRAN y eNodeB, el Evolved Packet Core, los bearers, el attach y el handover. |
| [Arquitectura del sistema 5G](./5g-system.md) | Intermedio | El sistema 5G de extremo a extremo: NSA frente a SA, el núcleo basado en servicios, las sesiones PDU, los flujos QoS y los procedimientos clave. |
| [5G NR y NG-RAN](./5g-nr-and-ng-ran.md) | Avanzado | La radio 5G: numerologías, estructura de trama, la pila de protocolos NR, massive MIMO y la división CU/DU del gNB. |
| [Núcleo 5G: SBA, PFCP, GTP-U y NGAP](./5g-core.md) | Avanzado | El núcleo cloud native: funciones de red, interfaces basadas en servicios, separación de planos de control y usuario, y sus protocolos. |
| [Voz: IMS, VoLTE y VoNR](./ims-and-voice.md) | Avanzado | Cómo funciona la voz en redes móviles totalmente IP: el IP Multimedia Subsystem, VoLTE, VoNR y EPS fallback. |
| [Open RAN](./open-ran.md) | Avanzado | Desagregar la red de acceso radio: arquitectura O-RAN, fronthaul abierto, el RIC, xApps y rApps, SMO. |
| [Network slicing](./network-slicing.md) | Avanzado | Varias redes lógicas con garantías distintas sobre una infraestructura compartida, de extremo a extremo en RAN, transporte y núcleo. |
| [5G privado y edge computing (MEC)](./private-5g-and-mec.md) | Intermedio | 5G para empresas e industria: redes privadas y de host neutral, espectro local y CBRS, y multi-access edge computing. |
| [Redes no terrestres (NTN)](./non-terrestrial-networks.md) | Avanzado | Satélites y plataformas de gran altitud en el 3GPP: GEO, MEO y LEO, conexión directa al dispositivo y NB-IoT por satélite. |
| [6G](./6g.md) | Avanzado | Lo que viene después del 5G: el marco IMT-2030, las líneas de investigación y el calendario del 3GPP. |
