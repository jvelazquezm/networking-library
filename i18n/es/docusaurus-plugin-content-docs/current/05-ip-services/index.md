# 05 · Servicios IP

Los servicios que hacen que una red IP sea usable y gestionable: direccionamiento automático, nombres, traducción de direcciones, hora precisa, priorización del tráfico, acceso seguro para la gestión y voz y vídeo en tiempo real.

## Temas de esta sección

| Tema | Nivel | Qué aprenderás |
| --- | --- | --- |
| [DHCP y DHCPv6](./dhcp.md) | Principiante | Configuración automática de equipos: el intercambio DHCP, opciones, relays, DHCPv6 y cómo diagnosticarlo. |
| [DNS, DNSSEC, DoT y DoH](./dns.md) | Principiante | El sistema de nombres de Internet: jerarquía, resolución, tipos de registro, caché, DNSSEC y DNS cifrado. |
| [NAT y PAT](./nat.md) | Principiante | Traducción de direcciones de red: NAT estático, NAT dinámico, PAT/overload, redirección de puertos y NAT de operador. |
| [Hora: NTP, NTS y PTP](./time-synchronization.md) | Principiante | Por qué importa la hora exacta y cómo la entregan NTP, Network Time Security y Precision Time Protocol. |
| [Calidad de servicio (QoS)](./qos.md) | Principiante | Clasificación, marcado, colas, policing, shaping y prevención de congestión, y cómo diseñar una política extremo a extremo. |
| [Gestión de equipos: SSH, SNMP, syslog, TFTP, FTP y SFTP](./device-management.md) | Principiante | Acceso remoto seguro, monitorización básica y transferencia de archivos hacia y desde los equipos de red. |
| [Voz y vídeo sobre IP: SIP y RTP](./voice-and-video.md) | Intermedio | Cómo funcionan las comunicaciones en tiempo real en redes IP: señalización con SIP, medios con RTP, códecs y requisitos de red. |
