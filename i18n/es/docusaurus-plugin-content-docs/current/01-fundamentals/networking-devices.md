# Dispositivos de red y sus funciones

**Nivel:** Principiante · **Sección:** [Fundamentos de redes](./index.md)

## Visión general

Cada tipo de dispositivo existe para resolver un problema concreto: los switches reenvían tramas dentro de una LAN, los routers mueven paquetes entre redes, los firewalls aplican la política de seguridad, los puntos de acceso conectan los clientes inalámbricos a la red cableada y las controladoras gestionan flotas de equipos de forma centralizada. Muchos equipos actuales combinan funciones (switches de capa 3, firewalls de nueva generación), así que conviene entender la función más que la etiqueta comercial.

## Conceptos clave

- Hubs (históricos), switches y switches de capa 3
- Routers
- Firewalls y firewalls de nueva generación
- Puntos de acceso inalámbricos y controladoras
- Equipos finales y servidores
- Appliances físicos frente a funciones de red virtuales
