# 13 · Automatización, programabilidad e IA

Gestionar las redes como código: los formatos de datos y las APIs que exponen los equipos, las herramientas que aplican configuración y recogen estado, las interfaces dirigidas por modelos de las plataformas modernas, las prácticas de ingeniería que hacen seguros los cambios y el papel creciente de la IA en la operación de redes.

## Temas de esta sección

| Tema | Nivel | Qué aprenderás |
| --- | --- | --- |
| [Enfoques de gestión de redes](./management-approaches.md) | Principiante | De la CLI equipo a equipo a la automatización, la infraestructura como código y las redes gestionadas por controladora o desde la nube. |
| [Formatos de datos: JSON, XML y YAML](./data-formats.md) | Principiante | Los formatos de datos estructurados que usan las APIs y las herramientas de automatización, y cómo leerlos y escribirlos. |
| [APIs REST](./rest-apis.md) | Principiante | Cómo funcionan las APIs REST: recursos, métodos HTTP y CRUD, códigos de estado, autenticación y herramientas como curl y Postman. |
| [Gestión de la configuración: Ansible, Terraform, Puppet y Chef](./configuration-management.md) | Principiante | Herramientas que aplican configuración a escala: con o sin agente, push o pull, declarativas o procedimentales. |
| [Python para ingenieros de redes](./python-for-networks.md) | Intermedio | Fundamentos de Python aplicados a redes: conectarse a equipos, analizar salidas, llamar a APIs y construir pequeñas herramientas. |
| [Plantillas y fuente de verdad: Jinja2 y NetBox](./templating-and-source-of-truth.md) | Intermedio | Generar configuraciones a partir de datos con Jinja2 y mantener el estado deseado en una fuente de verdad como NetBox. |
| [YANG, NETCONF y RESTCONF](./yang-netconf-restconf.md) | Intermedio | Gestión dirigida por modelos: modelos de datos YANG (IETF, OpenConfig, nativos), transacciones NETCONF y RESTCONF sobre HTTP. |
| [Telemetría y operación dirigidas por modelos: gNMI, gNOI y gRPC](./model-driven-telemetry.md) | Intermedio | Transmitir el estado de los equipos con suscripciones gNMI, operarlos con gNOI y montar un pipeline de telemetría. |
| [Automatización en el equipo: EEM y Python en el dispositivo](./on-box-automation.md) | Intermedio | Automatización que se ejecuta en el propio equipo: scripts por eventos, Cisco EEM, scripts de commit y eventos en Junos y Python en el dispositivo. |
| [NetDevOps, CI/CD y gemelos digitales](./netdevops.md) | Avanzado | Prácticas de ingeniería de software para redes: flujos con Git, pruebas, laboratorios virtuales, validación previa a los cambios y pipelines. |
| [IA en la operación de redes](./ai-for-networks.md) | Principiante | Aprendizaje automático, IA generativa y agentes de IA en redes: analítica, detección de anomalías, prompts y operación con agentes. |
