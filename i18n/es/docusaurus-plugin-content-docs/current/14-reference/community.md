# Comunidad

Las redes son un campo en el que los profesionales comparten con generosidad. Estos son buenos sitios para seguir aprendiendo después de los fundamentos. La mayoría están en inglés.

## Blogs y artículos

| Fuente | Enfoque |
| --- | --- |
| [Blog de ipSpace.net](https://blog.ipspace.net/) | Análisis profundo y neutral de enrutamiento, centros de datos y automatización |
| [APNIC Blog](https://blog.apnic.net/) | Operación de Internet, seguridad del enrutamiento, medidas |
| [RIPE Labs](https://labs.ripe.net/) | Investigación y operación de la comunidad RIPE |
| [Blog de Cloudflare](https://blog.cloudflare.com/) | Protocolos de Internet, DDoS, post-cuántica, rendimiento |
| [Practical Networking](https://www.practicalnetworking.net/) | Explicaciones claras de temas de nivel CCNA |
| [segment-routing.net](https://www.segment-routing.net/) | Segment Routing |
| [srv6.md](https://srv6.md/) | SRv6 |
