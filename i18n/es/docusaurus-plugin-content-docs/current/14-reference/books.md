# Libros

En cada área aparecen primero los libros gratuitos y abiertos. Muchos títulos de pago también están disponibles en bibliotecas por suscripción como O'Reilly Learning, que a menudo ofrecen empresas y universidades. Cada página de tema enumera además los libros más relevantes para ese tema.

:::info Las ediciones importan
Prefiere siempre la última edición, sobre todo en guías de certificación y en todo lo relacionado con 5G, cloud native o automatización.
:::
