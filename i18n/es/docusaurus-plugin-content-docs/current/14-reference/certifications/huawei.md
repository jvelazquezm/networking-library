# Huawei

El itinerario Datacom de Huawei tiene tres niveles: HCIA-Datacom, HCIP-Datacom (un examen troncal más especializaciones) y HCIE-Datacom (examen escrito y de laboratorio).

| Nivel | Alcance | Temas de la biblioteca |
| --- | --- | --- |
| HCIA-Datacom | Fundamentos de redes, conmutación, enrutamiento, WLAN, seguridad y nociones de automatización | Secciones [01](../../01-fundamentals/index.md), [02](../../02-switching/index.md), [03](../../03-wireless/index.md), [04](../../04-routing/index.md) y [05](../../05-ip-services/index.md); [Listas de control de acceso](../../11-security/acls.md), [Enfoques de gestión de redes](../../13-automation/management-approaches.md) |
| HCIP-Datacom | Tecnología troncal más especializaciones: enrutamiento y conmutación avanzados, redes de campus, planificación WAN, SD-WAN y automatización | [OSPF](../../04-routing/ospf.md), [IS-IS](../../04-routing/is-is.md), [BGP avanzado](../../04-routing/bgp-advanced.md), [Multicast IP: IGMP, PIM, SSM, MSDP y BIER](../../04-routing/multicast.md), [MPLS y LDP](../../07-service-provider/mpls.md), [MPLS L3VPN, 6PE y 6VPE](../../07-service-provider/mpls-l3vpn.md), [VXLAN, Geneve y EVPN](../../09-data-center-and-cloud/vxlan-evpn.md), [Fábricas de campus: SD-Access, LISP y VXLAN](../../09-data-center-and-cloud/campus-fabrics.md), [SD-WAN](../../06-wan-and-vpn/sd-wan.md), [YANG, NETCONF y RESTCONF](../../13-automation/yang-netconf-restconf.md) |
| HCIE-Datacom | Enrutamiento y conmutación avanzados, planificación y despliegue de campus, interconexión WAN (incluida SD-WAN), bearer WAN y automatización | [BGP avanzado](../../04-routing/bgp-advanced.md), [Segment Routing: SR-MPLS](../../07-service-provider/segment-routing.md), [SRv6 y uSID](../../07-service-provider/srv6.md), [EVPN](../../07-service-provider/evpn.md), [Fábricas de campus: SD-Access, LISP y VXLAN](../../09-data-center-and-cloud/campus-fabrics.md), [SD-WAN](../../06-wan-and-vpn/sd-wan.md), [Python para ingenieros de redes](../../13-automation/python-for-networks.md), [NetDevOps, CI/CD y gemelos digitales](../../13-automation/netdevops.md) |

Información oficial: [certificación de Huawei](https://e.huawei.com/en/talent/cert/).

:::note
Huawei llama a algunas tecnologías de otra forma (por ejemplo, «bearer WAN» para la red troncal de tipo operador con SR/SRv6). Consulta el temario oficial del examen para conocer el alcance exacto.
:::
