# Conceptos y programas de seguridad

**Nivel:** Principiante · **Sección:** [Seguridad](./index.md)

## Visión general

La seguridad empieza por el vocabulario y la mentalidad: qué proteges (confidencialidad, integridad, disponibilidad), de quién y cómo. Las amenazas explotan vulnerabilidades; los controles reducen el riesgo; las capas de defensa hacen que un fallo aislado sea soportable. Los controles técnicos solo funcionan dentro de un programa que incluya concienciación de usuarios, seguridad física y respuesta a incidentes.

## Conceptos clave

- Amenazas, vulnerabilidades, exploits y mitigación
- Confidencialidad, integridad, disponibilidad
- Defensa en profundidad
- Tipos de ataque habituales
- Concienciación, formación y control de acceso físico
- Marcos: NIST CSF, CIS Controls
