# Redes de operador

**Nivel:** Avanzado · **Temas:** 21

IS-IS, BGP a escala, MPLS, L3VPN, EVPN, Segment Routing, SRv6 y transporte. Cubre el nivel CCNP/CCIE Service Provider, JNCIP/JNCIE-SP y el programa SRC de Nokia.

## Objetivo

Diseñar y operar la red troncal de un operador con Segment Routing y servicios EVPN modernos.

## Proyecto final

Monta un núcleo IS-IS/SR-MPLS (o SRv6) con TI-LFA, reflectores de rutas, servicios L3VPN y EVPN, validación RPKI y telemetría gNMI.
