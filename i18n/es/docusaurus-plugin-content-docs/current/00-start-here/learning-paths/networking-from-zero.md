# Redes desde cero

**Nivel:** Principiante · **Temas:** 38

De «¿qué es un paquete?» a construir, proteger y diagnosticar una pequeña red empresarial. Cubre el nivel CCNA, JNCIA y Network+.

## Objetivo

Entender cómo viajan los datos por una red y ser capaz de construir, proteger, automatizar lo básico y diagnosticar una pequeña red empresarial.

## Proyecto final

Monta en un laboratorio virtual una red de dos sedes con VLAN, OSPF, VRRP, DHCP, NAT, ACL y Wi-Fi; después documéntala y arregla tres fallos que introduzca otra persona.

:::tip Cómo recorrer una ruta
Lee la visión general y los conceptos clave de cada tema, haz su laboratorio práctico y avanza solo cuando puedas explicar cada concepto clave sin apuntes.
:::
